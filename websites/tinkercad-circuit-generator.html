How to do it ?
  1. Create a JSON file with breadboards, parts, and wires.
  2. Assign each breadboard a stage starting at 1, with no gaps.
  3. Place each part on an existing breadboard using "brd#n.column".
  4. Connect terminals with wires using "part.terminal" pairs.
  5. Select or drop the file above, then confirm and print.
